【核心要求】
1. 只基于论文内容与可直接支持的上下文提取信息，不要臆测。
2. `common_core` 里的摘要、方法、发现、结论、贡献、局限必须尽量具体。
3. `type_specific_details` 里的变量、research gap、研究问题/假设必须遵守“证据约束”：
   - 找得到就提取。
   - 找不到就返回空字符串或空数组。
   - 不要为了填满字段而编造。
4. 如果论文不是实证研究，`core_variables` 可以全部为空数组。
5. 输出必须是纯 JSON，不要附加解释文字、Markdown、代码块。

【输出 Schema】
```json
{
  "common_core": {
    "title": "",
    "authors": [],
    "year": "",
    "journal": "",
    "doi": "",
    "summary": "",
    "key_points": [],
    "methodology": "",
    "findings": "",
    "conclusions": "",
    "relevance": "",
    "limitations": ""
  },
  "type_specific_details": {
    "paper_type": "",
    "theoretical_framework": "",
    "research_gap": "",
    "research_questions_or_hypotheses": [],
    "data_source_and_size": "",
    "analysis_technique": "",
    "core_variables": {
      "independent": [],
      "dependent": [],
      "mediators": [],
      "moderators": [],
      "controls": [],
      "other_core_constructs": []
    },
    "sample_characteristics_or_context": "",
    "future_research_directions": [],
    "extraction_confidence": ""
  }
}
```

【字段说明】
- `paper_type`: 如 empirical / conceptual / review / qualitative / mixed-method 等，可用中文或英文短语。
- `research_gap`: 作者明确提出的研究空白；若未明确写出则留空。
- `research_questions_or_hypotheses`: 论文中明确提出的问题、命题或假设。
- `data_source_and_size`: 数据来源、样本量、数据集、案例数量、访谈对象等。
- `analysis_technique`: 回归、SEM、fsQCA、实验设计、主题分析、扎根理论等。
- `core_variables`: 仅提取论文明确聚焦的核心变量或构念。
- `sample_characteristics_or_context`: 样本特征、国家/行业/平台/场景。
- `future_research_directions`: 作者提出的未来研究方向。
- `extraction_confidence`: 用简短文字说明提取把握度，如“high / medium / low”，也可补一句原因。

【写作标准】
- `summary` 用 200-300 字左右概括研究问题、方法、核心发现与结论。
- `key_points` 提炼 3-6 条最值得综述阶段使用的要点。
- 能提取到定量结果时，优先写出样本量、显著性、效应方向等关键信息。
- 不要输出“未提供相关信息”“未知”“N/A”“...”这类占位符；无法确定时用空字符串或空数组。
